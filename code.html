About SDG5 Gender Equality

SDG5 aims to achieve gender equality and empower all women and girls. Gender-biased language can perpetuate stereotypes and create barriers to equality. This tool helps identify such language and suggests more inclusive alternatives.

Common biases include occupational stereotypes (e.g., "nurse" vs. "doctor"), descriptive words (e.g., "assertive" for men vs. "bossy" for women), and pronoun usage (defaulting to "he" as generic).
